## 💡 事前準備 (Prerequisites)

このサンドボックス環境を利用するには、事前に以下の2つが必要です。

1. **VS Code**（すでにClaude拡張機能などを導入・使用している環境でOKです）
2. **Docker Desktop** のインストール
   - [Docker Desktop 公式サイト](https://www.docker.com/products/docker-desktop/) からダウンロードしてインストールを完了させ、起動しておいてください。
3. VS Code拡張機能：**Dev Containers**
   - コンテナ内でVS Codeを開くために必要です。Marketplaceからインストールしてください。

---

## 🚀 使い方 (How to Start)

既存のClaude拡張機能が入ったVS Codeの利便性を活かしたまま、安全なコンテナ環境へ切り替える手順です。

### 1. リポジトリのクローン
本リポジトリをローカルの任意の場所にクローンします。
```bash
git clone <本リポジトリのURL>
cd <リポジトリ名>


## 🛡️ セキュリティと隔離環境の確認手順

本環境が正しくサンドボックス化され、適切な権限で動作しているかは、ホスト側（Windows）のコマンドプロンプト（cmd）から以下のコマンドを実行することで目視確認（エビデンス確認）できます。

コンテナを起動した状態で、Windows側のコマンドプロンプトを開き、確認してみてください。
*(※ `<コンテナID>` は、現在起動中のコンテナIDに置き換えてください)*

### 1. マウント（共有フォルダ）の確認

## ドキュメント作成時のワンポイントアドバイス

「すでにClaude拡張を使っている人」に向けて配慮

* **設定の引き継ぎについて補足する**:
  VS Codeの拡張機能（Claude拡張など）は、ローカル環境（ホストOS）とコンテナ環境（Docker内）で**別々に管理**されます。
  そのため、「コンテナに入った後、もう一度Claude拡張の画面でAPIキーや設定を入れる必要があります」と一言添えておくと、「あれ、動かない？」という迷いを防げます。
  （※もし設定の手間を省かせたい場合は、前述の `.devcontainer.json` の `extensions` 項目にClaude拡張の識別子を入れておけば、コンテナ起動時に自動でインストールされます！）
